# 《中央帝国的军事密码》视频素材工程

项目是什么：**一套用 AI 造竖屏地理片的系统**，蒙古大迂回（1253-1259 年三路包抄南宋）只是测试用例（2026-10-13 定调 ADR-005）。成片规格：**竖屏 9:16（1080×1920），时长由内容定**；分工口诀“几何正确归机器，观感受众归后期”。
当前状态：首跑待开工 = **11 终章竖屏重制**（一炮五响：粮草+设计环+新料渲染+自动剪辑首单+复盘，见 TODO 待办重整段）
已完成功能：
- GES 旧产线（现降为横屏配菜）：12 组素材（01~11 + 03 高版对照，高版已胜）+ 生成器/校验器，`verify` 12 组全绿 [2026-10-13 运行确认]
- harness 图纸全套：video-pipeline 五步 + 设计环 + 导演执照六资质 + 镜头模板 T-01 + 术语词典 + 数据三层制（粮库/账本/手册）+ 后期 baocut 选型（ADR-006）
- `分集/11_终章/` 6 纸首个端到端交付；用户自渲横屏 mp4 已落盘
正在开发：无（等开工令：第一铲 = 11 事实卡编号迁移；等用户一句话：原版 03 删除 + .bak 确认）
最大风险：自建引擎渲染与 P0 地形粮（~10GB DEM + 影像）尚未落地；“震撼感”需擂台赛实测裁决（ADR-008）
下一步最重要任务：首跑五步走通一集竖屏成品

相关决策：见 decisions.md（ADR-001~011）

## 系统结构
数据存在哪里：书稿文件夹（坚果云跨机同步）。母版路线 = `蒙古大迂回_三路路线.kml`（17 地标）；GES 成品 = `视频制作/` 下 12 组 .esp + .kml（配菜）；新产线粮库 = `数字资产/粮库_军事密码/`（主题级一次建仓，P0 待入库）
依赖的外部服务：自建引擎数据（Copernicus DEM / Sentinel-2 / open-meteo / ERA5 待接）；Google Earth Studio（配菜，需用户账号）；坚果云同步；baocut（待装）
哪个部分出问题会影响什么：母版 KML 是 GES 配菜的坐标来源；CLIPS 表是镜头参数唯一来源；粮库账本不齐不开工（备菜闸）
