# 《中央帝国的军事密码》视频素材工程

项目是什么：为一本书制作配套地图动画视频（蒙古大迂回：1253-1259 年蒙古三路包抄南宋的行军路线）。用 Google Earth Studio（谷歌地球工作室）做镜头动画，成片约 2 分半。
当前状态：进行中
已完成功能：
- 11 组视频素材（01~11 按成片顺序；每组 = 镜头动画 .esp + 路线图层 .kml）——2026-09-28 已按 GES 标准格式全部重写，并通过机器校验
- 素材生成器 + 校验器（改高度/角度/时长后可一键重新生成）
- 母版路线文件（17 个地标）核对无误
- AI 接手文档体系（CLAUDE.md/AGENTS.md 复制对 + 素材清单）+ 记忆系统
正在开发：无（等待用户在 GES 里验收 02、03 的镜头方向）
最大风险：镜头朝向的最终正确性只能由用户在 GES 里实测（AI 没有账号、无法代测）。09-28 修复过一次"方向反向"问题，现用方案依据 Google 官方约定，置信度高但未经实测
下一步最重要任务：用户在 GES 导入 02/03 验证镜头方向 → 通过后按 01→11 批量渲染
相关决策：见 decisions.md

## 系统结构
数据存在哪里：书稿文件夹（坚果云跨机同步）。母版路线 = `蒙古大迂回_三路路线.kml`；成品 = `视频制作/` 下 11 组 .esp + .kml
依赖的外部服务：Google Earth Studio（需用户 Google 账号）；坚果云（文件同步）
哪个部分出问题会影响什么：母版 KML 是所有镜头和路线的坐标来源，改错会波及全部 11 组素材；.esp 是生成物（由 make_video_assets.py 生成），手改会与脚本脱节
