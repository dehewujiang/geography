配菜（GES 旧线，降级保留）：母版 KML（17 地标）→ make_video_assets.py（CLIPS 表 = 相机路径/高度/俯角/时长 + .kml 剪取规格）→ `generate` 生成 .esp（modelVersion 17，属性树骨架不可动）→ `generate-kml` 重剪路线层（与成品逐字节一致）→ `verify` 解码校验（退出码 0/1）→ `视频制作/XX.esp + XX.kml` → 用户导入 GES → 云渲染 → 横屏空镜

关键技术约束：
- .esp 数值 = (实际值−下限)/(上限−下限)，固定标准区间：lon ±180、lat ±89.9999、alt −500~65117481、rotationX 0~360（罗盘方位角：北=0° 顺时针）、rotationY 0~180（0=俯瞰，90=平视）
- 每个属性块必须同时声明 minValueRange + maxValueRange；不写负方位角
- 生成器零依赖（纯标准库，禁装 numpy）
- 脚本硬断言母版地标数=17（增删地标须同步改断言）
- 文档为复制对，改一份必须同步另一份；修改 .esp 前先 git checkpoint
- .kml 剪取规则已并入脚本（2026-09-29，`generate-kml`）；项目外临时区不再承载任何规则
