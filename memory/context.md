# 技术上下文
更新时间：2026-09-28

核心模块关系：
母版 KML（17 地标）→ make_video_assets.py（CLIPS 表 = 11 段镜头的相机路径/高度/俯角/时长）→ `generate` 生成 11 个 .esp（modelVersion 17，属性树骨架不可动）→ `verify` 解码校验（与路线坐标/方位角逐项比对，退出码 0/1）→ `视频制作/XX.esp + XX.kml` → 用户导入 GES → 云渲染 → 剪映拼接。

关键技术约束：
- .esp 数值 = (实际值−下限)/(上限−下限)，固定标准区间：lon ±180、lat ±89.9999、alt −500~65117481、rotationX 0~360（罗盘方位角：北=0° 顺时针）、rotationY 0~180（0=俯瞰，90=平视）
- 每个属性块必须同时声明 minValueRange + maxValueRange；不写负方位角
- 生成器零依赖（纯标准库，禁装 numpy）
- 脚本硬断言母版地标数=17（增删地标须同步改断言）
- 文档为复制对，改一份必须同步另一份；修改 .esp 前先 git checkpoint

当前活跃风险：
- 朝向约定（罗盘方位角）基于 Google 系约定 + 第三方实测，无 GES 官方直接文档；若用户实测仍反向 → `build_esp` 里 pans 全体 +180° 重新生成
- GES 只能由用户验收（需账号）
- 09_两湖南线有一帧方位角为 −6.2°（最短弧连续化产物，数学等价 353.8°）；若该片段镜头异常优先查这里

用户长期目标：蒙古大迂回成片（剪映拼接 + 字幕 + 音乐，约 2.5 分钟）
