# 粮库（数据仓库）

> 这是流水线的**仓库层**：数据真身住这里，AI 渲染只从这里读，**LLM 永不亲手下载数据**。
> 三层制详情见 `.claude/skills/video-pipeline/references/data-sources.md`（ADR-010）。

## 目录约定

**主题级一次建仓**（2026-10-13 用户定调：一次下全、之后不依赖网络）——数据文件夹按**主题**分，不按集：

```
粮库/
  _manifest/manifest.md        账本层：每份料一条记录（不齐不许渲染）
  DEM_Copernicus_GLO30/蒙古大迂回/   高程换血主粮（12片矩形裁剪的 .tif）
  Sentinel2_无云合成/蒙古大迂回/     底图换血主粮
  GeoNames_中国/               地名异名册（常备，主题无关）
  HydroRIVERS/                 水系矢量（常备）
  天地图_标签/                 中文标签层（key 运行时，天然增量）
  Wikimedia_图料/蒙古大迂回/         历史地图/老照片（逐图授权记录，天然增量）

例外条款（明示不丢原则）：
  ① 最高精档贴脸镜头影像 = 按需补小块（全域最高精=数百GB，不允许）
  ② 天地图 key/授权图片类 = 依赖人工账号/授权，天然增量
```

**旧按集空夹（`11_终章/`）**：建仓当天多余的产物，空目录留着无害；将来要用再进。

## 收货流程

1. 数据放进上面的对应文件夹（分集的放 `11_终章/` 子夹）
2. **喊 AI 一声"粮入库了"** → AI 扫描文件夹 → 代写 manifest 记录（文件名/版本/下载日期/来源/标注原文/覆盖范围）
3. manifest 记完之前，本份料不许进流水线使用

## 格规纪律

- 下载到手的原始文件**永远改名勿动**；需要加工（裁剪/调色）的产物另存派生文件夹，皆记 manifest
- 凡 AI 自取的料，同一条规矩走（下载完 AI 自己记 manifest，不豁免）

## 坚果云同步提醒（重要，需用户手动设置）

粮库里是 GB 级影像，**请把 `粮库/` 目录从坚果云选择性同步里摘除**（本地保存即可）——具体开关在坚果云客户端设置里，由用户手动操作，AI 不动同步设置。
