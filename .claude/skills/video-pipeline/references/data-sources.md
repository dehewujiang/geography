# 抽屉：数据源手册（data sources — 全流水线的免费公开数据）

> 一句话：素材层的粮库——在哪道工序用、免费怎么领、标注义务原文；**凡引数据必留标注（ADR-007 一票否决）**。
> 分级依据：与用户 2026-10-13 对齐（P0 立竿见影换血 / P1 直补观众槽点 / P2 按集启用）。
> 架构（2026-10-13 补）：**三层制**——①仓库层=粮库/ 本体（LLM 永不碰）→②账本层=manifest（机器记）→③手册层=效果-数据映射表（喂导演）。导演点菜、备菜脚本下厨、LLM 不编码下载。

## 三层制细则

- **粮库/**（项目根新建，数据真身）：`粮库/{数据名}/{主题}/{文件}`；**从坚果云选择性同步中摘除**（开关用户手动设，影像 GB 级不进同步盘）
- **manifest**（每料一条账）：`文件名｜版本｜下载日期｜来源｜标注原文｜覆盖bbox`；**manifest 不齐，渲染不开工**（机器卡口）
- **效果-数据映射表**（初仓见下 §效果映射表；导演设计时的可选菜单；新效果闭环走"需开发"申报）

| 数据 | 入库模式 | 时机 | 体量级 |

| HydroSHEDS/HydroRIVERS | 粮库（按流域裁） | **常备**（跨河叙事高频） | 小 |
| CHGIS | 粮库（主题定稿一次全取） | 主题级 | 数十~百 MB |
| OpenHistoricalMap | 现拉 bbox extract + 落粮库 | 按集启用 | 小 |
| Landsat 时序 | 粮库（敲定"年代对比"镜头的集才下） | 按集启用 | 数百 MB/集 |

**统一规矩：凡粮库者一律上 manifest，凡现拉者一律逐批落盘。**

## 备菜工序（流水线新挂：事实锁死后、设计环前）

```text
备菜清单 = 脚本按本集bbox+事实卡需求算出"缺哪些料" → 拗数下载入粮库 → 写 manifest
          → 生成"本主题粮库清单"页（喂设计环第⑦样输入）
纪律：下载动作只由备菜脚本执行；LLM/canvas不许亲手逐段抓数据
```

## P0 换血级（先于擂台赛第②③牌落实）

### Copernicus DEM GLO-30（高程换血）
- 用途：第③素材层全部（飞行巡航/翻山仰视/剖面爬杆/贴沟加密）
- 强在：30m 全球，横断山区质量优于现有 SRTM；欧空局持续维护
- 领取：Copernicus 官方门户（开放下载，无需商店级审批）；大块下载后脚本裁剪入库
- 标注写法：`高程: Copernicus DEM GLO-30 (ESA)`
- 附注：AW3D30（JAXA，注册制）作交叉核验第三源，不并轨

### Sentinel-2 无云年度合成（底图换血）
- 用途：自建引擎 basemap；解 Esri 瓦片拼接硬边问题
- 强在：10m 真彩、无接缝、色彩可控；全免费开放许可
- 领取：Copernicus Data Space（免费注册 key）；年度无云合成一次取全，调色脚本化
- 标注写法：`影像: Sentinel-2 L2A (Copernicus)`

## P1 直补观众槽点（"好短/缺天时/地名漏歧"三件后事）

### ERA5 再分析（天时层）
- 用途：每集"季节/天气档"事实——**克制结论为"气候近似"**（历史月份不可测，取气候均值 1980~2020），标注"气候近似"三字入卡
- 领取：ECMWF Climate Data Store 免费；或 open-meteo 历史 API
- 落地纪律：**拉回即永久缓存**（climate_cache，一次采样终身复用），不再踩 429 限流坑

### GeoNames（地名消歧）
- 用途：古今异名备选、同名消歧（"这乌江不是那乌江"槽点的机器解）
- 领取：geonames.org 全量 dump（CC-BY）；异名字典（alternatenames）为主用部分
- 标注写法：`地名: GeoNames (CC-BY)`

### 天地图（中国区标签与合规）
- 用途：中文地名权威显示层；中国境内底图合规最优解
- 领取：tianditu.gov.cn 免费 key（个人额度 `[推测]`，够试点量级）
- 附注：与 Sentinel-2 影像层并行分层显示，中文标签叠影像

## 雷区（永禁，写死）

- **Google 地图瓦片直抓拼接** = 违约；Google 系画面只走 GES 官方管线拿（且**成片须手加署名**——GES 导出画面无内嵌水印，标注义务在用户侧履约 `[文档确认=GES条款要求署名；其卡片是否遮标=推测]`）
- **GADM 行政界**：免费但**禁商用**——当前"内容免费"模式可用；日后把系统包装为服务出售即触雷（与 ADR-006 牌照同款逻辑），届时换天地图官方界
- 任何"不留标注"的省事方案都不许进出厂检查单
