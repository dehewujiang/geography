# 抽屉4：亲眼验收（第4步细节，只能用户做）

> 目标：AI无法代开 earth.google.com/studio，这步必须用户亲手播一遍。
> 2026-10-12 升级：用户没有专业术语也能验收——**三件套翻译层**：点选验收单（用户出眼睛）+ 截图体检（AI 出先手报告）+ 问题单闭环（文档出词汇和修法）。
> 本抽屉是**主题无关模板**：`【主题名】【镜头名】` 两处按主题替换即可复用。

## 0. 分工一句话

用户出眼睛和直觉 → 文档出词汇和修法 → 截图分析出先手报告 → 问题单出闭环。
用户**永远不需要**说出"俯仰角"这类词；勾选+大白话即可。

## 1. 点选验收单（用户操作：每题勾一个，允许多选/手写大白话）

### 通用六题（每个镜头都过一遍，任何主题通用）

```
镜头速度      □A 匀速溜达像开车定速巡航   □B 忽快忽慢像油门踩抽     □C 起步收尾很猛像被弹射
山体/地面     □A 立体有明暗看得清沟壑     □B 灰白一片像隔着毛玻璃    □C 看不见地面全是天
开头读图      □A 开头有停顿让我看明白     □B 一上来就动看不懂在哪
光线感觉      □A 有斜阳影子明暗分明       □B 平平的像复印纸        □C 太暗看不清
路线还原      □A 镜头贴着彩色路线走       □B 路线在画面里看不见      □C 镜头和路线各走各的
画面污染      □A 干净没有异物             □B 有现代城市/建筑穿帮     □C 名字太小或被云挡
```

勾了 B/C = 过关项反着填回 CLIPS 表对应参数（修法映射见 `ges-expert.md` §4 故障速查表）。

### 编码类三题（首次导入必查，之后回归用）

```
方向        □A 镜头面朝飞行方向        □B 背对/反向        □C 歪向一侧像镜像
沿路        □A 镜头跟着路线点走        □B 直线抄近道不跟弯
高度        □A 山不穿镜头顶不钻地      □B 有撞山/钻地瞬间（第几秒:____）
```

### 逐集特查题（点 tableName 替换）

- 开场/终章类镜头：□ 拉起收全景有"一口气松开"感 □ 结尾停在看得清落点的画面
- 会师/围城类镜头：□ 到达时能看到目标城市/城塞的立体轮廓
- **每集验收顺序：01 → 03 → 11 先打样（覆盖定场/贴山/拉起三种语法），样过了再扫其余**

## 2. 截图体检（AI 先手报告，用户复核）

用户重测时随手截 3~5 张（开头/中段/结尾各至少一张）丢给 AI：

1. AI 用看图分析，按 `cinematography.md` 的基线逐项报告：达标项/偏离项/偏离特征——**实验性结论一律贴 [推测] 标签，AI 是助手，用户的眼睛才是第二来源**。
2. 与用户点选结果互相印证：两边说一样 → 结论可信；说不一样 → 以用户为准，AI 分析入复盘存疑区。
3. 体检报告落进该集问题单，不单独成文。

## 3. 问题单模板（闭环格式，主题无关）

```text
【主题名】【XX集问题单】
- 勾选：速度=B 山体=B 画面污染=B(现代高楼出现在__)
- 截屏：附图（AI 体检结论:[推测]...）
- 第几秒：____
- 专业归因（AI 填）：如 时间未按里程分配/俯角超出35°/buildings 未关/线宽过细
- 判给：□事实(回步1) □叙事(回步2) □呈现(回步3)
- 待改参数（AI 填）：如 CLIPS 04_中路 tilts 数组第 i 点、worldTime、.kml LabelStyle
- 状态：□待改 □已改待重测 □重测通过
```

- 问题单存到 `分集/XX_YY/问题单.md`（新主题照建同名目录）；同一张单子逐轮勾选，改没改一目了然。
- 判给事实就回第1步，判给呈现就回第3步，不在GES里凑合。

## 4. 验收定性（最后一关）

- 用户点头"这集能用" → 才许进第5步（后期）。
- 达不到"好"只到"能用"：允许放行，但问题单保留存疑区，下轮迭代优先处理。
- AI 或文档任何一方都不能替用户签"已验收"——机器只能出先手报告。
