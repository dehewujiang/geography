# 剪辑师模块（出片规格 + 后期操作清单）

> 目标：从 GES 素材到可发布成片的整条链，参数一次定死，每期照做。
> 本周期全部设计决策围绕一个前提：**成片 = 竖屏短视频（抖音/视频号 9:16）**。

## 0. 自建引擎线规格（主线；ADR-014，2026-10-15）

> 本节是 Blender+DaVinci 主线的交接规格。§1~§4 为 GES 配菜线历史规格（ADR-012 后 GES 降配菜，留作对照），与主线冲突处以本节为准。DaVinci 首单细则（脚本口操作序列翻译）待本机定位后补写。

### 0.1 渲染交付规格（Blender → DaVinci）

- 主层：EXR 16bit（PNG 16bit 兜底），**2160×3840 超采样 2 倍**，DaVinci 缩至 1080×1920——白赚一档锐度。
- 辅助分层：雾深度（Mist）、物体身份（Cryptomatte）、视图层（前景/地形/标注分离）随帧同出——后期无损调色、局部加光效的原料。
- 色彩空间：EXR 按线性交付，DaVinci 侧线性处理 + 共用 LUT（LUT 本体待做，见 ADR-014 影响项）。
- 命名契约：`{集}_{镜头}_{帧号}_{层}.exr`——DaVinci 脚本口批量导入靠它。
- 体量：分层 EXR 每集 GB 级 `[推测]`——渲染产物放同步盘外（同粮库逻辑），项目内只留清单。

### 0.2 配音工序（ADR-014：用户亲口念）

- 声源=用户本人；TTS 等系统跑顺后再评估，届时涉费用先问（红线不破）。
- 录法：安静房间，手机离嘴约一拳；照文案逐句录，每句 2~3 条选最好；情绪参照配方表的情绪标注表（导演已排标签）。
- 存放：`分集/XX_YY/配音/`，文件名=句序（如 `01_钩子.wav`）；文件齐了进后期包清单。
- 验收：用户自己回听不卡——与 step2"亲口念顺"合并成一步做完。

### 0.3 字体基准（ADR-014）

- 正文/字幕/3D 标签=思源黑体；标题强调=思源宋体；授权 SIL OFL 免费商用。
- 毛笔字卡字体另挑（必须可商用，挑时验授权原文）——待办。
- 字体文件待下载入粮库（建 `字体/` 文件夹 + 上 manifest）。

## 1. 渲染规格（GES Render 面板，人工操作）

```
分辨率      3840 × 2160（4K 横版 master，不管成片是竖的）
帧率        30 fps
运动模糊    开（高速飞行镜头的"糊出速度感"，最值钱的一个开关）
导出        PNG 图片序列（无二次压缩；禁止录预览/录屏）
```

- 为什么 4K 横版：竖屏成片只取中央 1/2.25 宽度，等于保留"二次构图"自由度；横版平台也直接可用。
- 4K 渲染慢是正常的，序列帧拷进剪辑软件直接吃。

## 2. 剪辑时间线（剪映/PR）

```
GES 序列帧 → 1080×1920 竖屏时间线（中央裁切）
     ↓
① 按解说节奏切镜头（每段首尾各有约 0.5s 可切区域——缓动已内建）
② 叠地名标题（一集 ≤4~6 个，只上叙事落点；出现时机跟解说词严格对齐）
③ 叠解说配音 + 字幕
④ 统一调色（一套 LUT 套全部素材；GES 侧已统一傍晚光 worldTime 0.8，这是 LUT 能拉平的前提）
⑤ BGM 压混出片
⑥ 路线生长/省面高亮动画（GES 做不了逐段生长、只支持整层淡入淡出——D 判决 2026-10-12，描线生长一律剪辑里做；整层淡入留给开场/结尾）
```

## 3. 交付物定义（流水线"成品"的边界）

AI 自动产出 → 用户只做导入和发布：

| 交付物 | 说明 |
|---|---|
| `视频制作/XX_*.esp` + `XX_*.kml` 成对素材 | `generate`/`generate-kml` + `verify` 通过 |
| 渲染操作清单 | 一页纸：拖入顺序、Render 面板参数、输出目录 |
| 剪辑节奏表 | 每段素材的时长/入点/出点建议 + 与解说词逐句对齐的标题时间轴 |
| 字幕文案 + 调色说明 | 一套 LUT 名称/参数 |
| 事实卡/问题单 | 见 step1/step4 抽屉 |

**红线**：`verify` 没过不进 GES；用户没重测验收不进后期；后期没套 LUT 不发布。
