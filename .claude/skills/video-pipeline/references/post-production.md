# 剪辑师模块（出片规格 + 后期操作清单）

> 目标：从 GES 素材到可发布成片的整条链，参数一次定死，每期照做。
> 本周期全部设计决策围绕一个前提：**成片 = 竖屏短视频（抖音/视频号 9:16）**。

## 1. 渲染规格（GES Render 面板，人工操作）

```
分辨率      3840 × 2160（4K 横版 master，不管成片是竖的）
帧率        30 fps
运动模糊    开（高速飞行镜头的"糊出速度感"，最值钱的一个开关）
导出        PNG 图片序列（无二次压缩；禁止录预览/录屏）
```

- 为什么 4K 横版：竖屏成片只取中央 1/2.25 宽度，等于保留"二次构图"自由度；横版平台也直接可用。
- 4K 渲染慢是正常的，序列帧拷进剪辑软件直接吃。

## 2. 剪辑时间线（剪映/PR）

```
GES 序列帧 → 1080×1920 竖屏时间线（中央裁切）
     ↓
① 按解说节奏切镜头（每段首尾各有约 0.5s 可切区域——缓动已内建）
② 叠地名标题（一集 ≤4~6 个，只上叙事落点；出现时机跟解说词严格对齐）
③ 叠解说配音 + 字幕
④ 统一调色（一套 LUT 套全部素材；GES 侧已统一傍晚光 worldTime 0.8，这是 LUT 能拉平的前提）
⑤ BGM 压混出片
```

## 3. 交付物定义（流水线"成品"的边界）

AI 自动产出 → 用户只做导入和发布：

| 交付物 | 说明 |
|---|---|
| `视频制作/XX_*.esp` + `XX_*.kml` 成对素材 | `generate`/`generate-kml` + `verify` 通过 |
| 渲染操作清单 | 一页纸：拖入顺序、Render 面板参数、输出目录 |
| 剪辑节奏表 | 每段素材的时长/入点/出点建议 + 与解说词逐句对齐的标题时间轴 |
| 字幕文案 + 调色说明 | 一套 LUT 名称/参数 |
| 事实卡/问题单 | 见 step1/step4 抽屉 |

**红线**：`verify` 没过不进 GES；用户没重测验收不进后期；后期没套 LUT 不发布。

## 4. 已知未决项（诚实清单）

- fov 相对值→真实角度映射未标定（做推拉前先实测一次）
- worldTime 0.8≈19:12 的精确对应未验证（用户 GES 目测确认）
- 竖屏裁切中"路线线宽/字号"是否需要单独一版 .kml（若 4K 裁切后线太细，出竖屏专属线宽版）
