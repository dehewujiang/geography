# 分卡A：手画出母版（Google Earth，最顺手）

> 什么时候用：路线少、边想边改；新书第一版推荐先手画。

## 步骤（只做这6下）

1. 打开 Google Earth（电脑版 Pro 或网页版 earth.google.com）。
2. 新建文件夹=书名，如“新书母版”。
3. 画地点：点“添加地标”，起名=书中叫法，说明里写出处。
4. 画路线：点“添加路径”，按行军顺序依次点，线名=路线名（如东路）。
5. 右键文件夹 → “将位置另存为” → 存成 `XX母版.kml`（不是kmz）。
6. 收尾：把文件放项目根目录，原名不动；同时在 `素材/<主题名>/` 记一行：谁画的、哪天、依据哪页书。

## 检查（存之前看一眼）

- 点和线都有名字，不叫“未命名路径”。
- 一条路线就是一条线，不一段一存。
- 经纬度是 WGS84（Google Earth默认就是，别用别的地图纠偏过的数）。
