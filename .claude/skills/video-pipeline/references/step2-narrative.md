# 抽屉2：叙事定稿（第2步细节）

> 目标：定“先讲什么”。输入事实卡，输出文案+分镜，不碰镜头数值。

## 1. 前3秒只讲冲突

- 不铺背景。好例子：“放着近路不走，为什么？”坏例子：“蒙古历史背景是……”。
- 每集开头一句话钩子，写在文案第一行；钩子由用户拍板（三选一或直接定）。
- 钩子里的每个数字必须出自事实卡，不许现编数字当钩子。

## 2. 一集只答一问，优先答“为什么”

- 一集一问（如东路/中路/西路各一集），结尾留下一集的问题。
- 问法排序：为什么（动机/代价）> 去哪（路线）> 是什么（复读）。事实卡的动机/代价栏就是“为什么”的料。
- 事实卡再厚，一集只用一条路线，多余的记“下集用”。

## 3. 文案和字幕一致，每句可溯事实卡

- 口播说什么字幕就写什么，地名第一次出现必带地图定位。
- 【单源】事项不进文案精确表述；事实卡存疑点不许洗成肯定句。
- 用户能一口气念下来不卡，才算定稿。

## 4. 分镜（给第3步的单子）

- 按 `make_video_assets.py` 的 `CLIPS` 表格式写：哪集、用哪条路线、哪几个地标。
- 只写要求（高/低、快/慢），不直接改 `.esp` 数值。
- 时长对照：口播上限≈镜头秒数/60×220字；默认前紧后松+地图停顿，不必说满。

## 5. 交稿前三硬伤自查（有一条就打回重写）

1. 空钩：钩子只有动作没有险/奇/悬，观众会问“所以呢？”
2. 地名复读：正文全是地图上能看见的字，没有一句“为什么”。
3. 无力结尾：观众还没在乎这支队伍，留的问观众不会关心。

## 产出验收

- 文案全文 + 分镜单 + 钩子一句话，三样齐了才许进第3步。
- 文案每句能指到事实卡的具体栏，指不出的删掉。
