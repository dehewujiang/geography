# 抽屉2：叙事定稿（第2步细节）

> 目标：定“先讲什么”。输入事实卡，输出文案+分镜，不碰镜头数值。

## 1. 前3秒只讲冲突

- 不铺背景。好例子：“3万人怎么绕过整个草原？”坏例子：“蒙古历史背景是……”。
- 每集开头一句话钩子，写在文案第一行。

## 2. 一集只答一问

- 11集一集一问（如东路/中路/西路各一集），结尾留下一集的问题。
- 事实卡再厚，一集只用一条路线，多余的记“下集用”。

## 3. 文案和字幕一致

- 口播说什么字幕就写什么，地名第一次出现必带地图定位。
- 用户能一口气念下来不卡，才算定稿。

## 4. 分镜（给第3步的单子）

- 按 `make_video_assets.py` 的 `CLIPS` 表格式写：哪集、用哪条路线、哪几个地标。
- 只写要求（高/低、快/慢），不直接改 `.esp` 数值。

## 产出验收

- 文案全文 + 分镜单 + 钩子一句话，三样齐了才许进第3步。
