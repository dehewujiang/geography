# 抽屉1：事实锁死（第1步细节）

> 目标：定“什么是真的”。本步改只改母版KML和事实卡，别处不动。
>
> 铁律：书在项目里时，料由AI从书中提炼，不许问用户要。
> 提炼完给人审，人只审“对不对”，不替AI找书。

## 0. 母版怎么来（四选一，不限于本书）

| 情况 | 读哪张分卡 | 产出 |
|---|---|---|
| 有书稿没坐标（本书走的这条） | `kml-extract.md`（AI读书提炼） | `XX母版.kml` |
| 路线少、边想边改 | `kml-hand.md`（手画） | `XX母版.kml` |
| 坐标成表、路线多、以后复用 | `kml-code.md`（代码拼） | `XX母版.kml` |
| 手里已有GPX/GeoJSON/SHP/CSV | `kml-convert.md`（格式转） | `XX母版.kml` |

- 本书现状是第一种已提前生成：`蒙古大迂回_三路路线.kml`就是母版（AI读epub提地点、跑脚本生成、再比对）；新书没生成就按上表现做一个再往下走。
- 四种产出都是同一个东西：根目录一个母版kml + `素材/`一行来源说明。

## 1. 找原始素材（AI自己动手）

- 书稿/地图/史书扫描件存 `素材/`（没有就新建），原名不动，另加一行来源说明。
- 有书稿没坐标：先按 `kml-extract.md` 跑“读书→地点表→人审”，地点表直接作为事实卡的输入。
- 已有母版只认一个（现任母版见根目录L1文件角色表）。备份只读不删。

## 2. 史料核对

- 一事一出处：一条路线至少两个来源对上才算数。
- 对不上就空着写“存疑”，不许为了顺而编一条。
- 单源规则：只在一处见到的事项（月份、旧名、数字、死因等）标【单源】，文案中避开精确表述；书中有年份无月份时，不许从别处借月份来配。

## 3. 权威三档（书与网络同一把尺）

| 档 | 包含 | 能干什么 |
|---|---|---|
| 一档 · 史料/方志/考古/官方学术 | 正史原文、地方志、考古报告、学术论文、官方志书 | 可进事实卡当出处 |
| 二档 · 官方媒体/权威科普 | 国家级媒体、省级以上官方号、认证机构 | 可当核对源，进卡须注明“二档” |
| 三档 · 自媒体/网文 | 公众号、短视频、论坛、百科 | **只当线索，永远不进事实卡** |

- 本书算一源（作者认定），仍须第二源才能去【单源】标。

## 4. 网络核对与补充（书为底、网为证、权为尺）

- **顺序写死**：先从书中提取 → 再上网核对/补充 → 回填事实卡。书是底稿，网是证人，主从不许颠倒。
- **两类分治**：
  - 核对类（书已有，上网验）：双源制沿用，对上才去【单源】标。
  - 补充类（书太概括，上网补细节数据）：**只有一、二档能进卡**，三档搜到再顺也不进，只当找一档的线索。
- **打架时谁赢**：按权威档裁，不按谁后出现。书=作者认定的一源；更高档网络源可覆盖，但卡上必须留痕：“书说X，源Y说Z，取Z”。
- **出处纪律**：进卡的网络出处必须是可点开的原文链接+篇名/机构+日期；AI转述、摘要、搜到的只言片语**不算出处**——搜索结果本身会编，链接打不开的不进卡。

## 5. 取舍（打架时谁赢）

- 以母版KML为准，另版记入备注，不并存两条线。
- 增删地标必须同步改 `make_video_assets.py` 的断言，否则 `verify` 会拦（现任断言数见脚本，勿硬记）。

## 6. 产出：事实卡一页（模板，通用版）

```text
【XX集事实卡】时间/地点/路线/人物/出处1/出处2/
动机（为何如此）/代价悬念点（反常/数字对比）/终局伏笔/
网络补充条目（每条：内容/链接/几档/核对谁）/打架留痕（书说X·源Y说Z·取Z）/
存疑点【单源标】/免责句
```

### 6.1 编号字段层（2026-10-13 升级：事实卡第二形态，设计环的粮草）

总表之外，每条硬事实必须单列成**编号条目**（设计稿靠编号引用，可追溯防编造）：

```text
F-## ｜[空]空间 / [序]时序·天时 / [量]数量 / [疑]存疑 / [钩]叙事钩子
     ｜事实一句（含数字单位）
     ｜来源：出处1/出处2（【单源】标则只写一个）
```

- 示例：`F-17｜[量]翻越高黎贡山最高点海拔4119m｜来源：母版KML+高程路由kindgrid实测`
- **无编号的事实不许进分镜**（design-loop 机器卡口查引用编号存在性）。
- 天时事（季节/天气）必须单列 [序] 条目——上一参照片观众槽点来源，防漏。
- 现有事实卡逐步改造补编号；11 集旧卡为首改样本（迁移记 TODO）。

- 出处和补充条目里的链接必须能点开；三档内容不许出现在这张卡上。

- 动机/代价/伏笔三栏是文案的米，没这三栏文案只能复读地名——提炼时必须从书中找，不许空着进第2步。
- 免责句固定带一句：“路线为示意，非精确国界”。
- 验收：事实卡写完 + `verify` 能跑过，才许进第2步。
