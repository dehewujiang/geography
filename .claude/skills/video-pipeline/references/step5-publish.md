# 抽屉5：发布复盘（第5步细节）

> 目标：标题封面和正片同等重要，发完记一笔，下集只改一处。

## 1. 发布包固定（每集一个）

- 文案 + 事实卡 + esp/kml + 封面2版 + 标题3选1。
- 坚果云同步完再测GES，别在同步一半时播。

## 2. 合规三件套

- 音乐/字体只用可商用的。
- 口播+字幕带一句：“路线为示意，非精确国界”。
- 评论区置顶史料来源，质疑先记下来不吵架。

## 3. 复盘一行（模板）

```text
【XX集复盘】完播率/跳出点/质疑/下集只改一处是什么
```

- 一集只改一处，改完进下一集第1步。
- 验收：标题封面定稿 + 复盘一行写完，才算一集走完。
